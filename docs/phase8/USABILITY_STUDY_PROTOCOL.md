# Student study protocol (prepared, not conducted)

Owner: designated campus study coordinator, appointment pending. Stage 1 plans
3–5 formative participants; revise unclear tasks/procedures and version the protocol
before Stage 2 (approximately 8–12 additional participants). Targets are planning
choices, not statistical guarantees. Recruitment requires approval and readiness
sign-off. Do not pool changed protocol versions without reporting the difference.

Before each session: complete [readiness checklist](PILOT_READINESS_CHECKLIST.md),
obtain approved consent, allocate pseudonymous session code, verify staged fixture
state/account role, browser/input/device, readiness and no private real data.
Pilot the script with researchers first; this is not participant evidence. No
password recording or observer account switching on behalf of a participant.

Moderator opening: “Please try the staged tasks in your own way. We are studying
the interface. You may stop or skip any task. Please avoid entering personal details.
Tell us what you expect to happen.” Do not explain controls or correct uncertainty
comprehension before it has been measured. Separate comprehension questions from
the participant-facing task. Use [task cards](USABILITY_TASKS.md) verbatim.

Start timing when instruction has been read and participant says ready; end at
the card's verified outcome, participant abandonment, safety stop or observation
window. Default window 8 minutes per task (U09 10 minutes); stop and record failed
if incomplete, without pressure. Window is a study setting, not a performance SLA.
Log interruptions separately via recovery code; timing stays elapsed wall time,
including interruptions, so durations remain comparable. Never silently subtract
delays. Label observer estimates and round to whole seconds. Missing timing stays
blank, never zero. Breaks occur between tasks. Plan about 75–100 minutes including
consent, breaks and debrief; offer split sessions with distinct codes if approved.

Assistance: first wait; after a request or 60 seconds stalled, one neutral goal
restatement is a minor_hint. Specific control directions or demonstration are
substantial. Record assisted if any hint was used and task completed; failed if
not completed regardless of assistance. Safety intervention always takes priority.
Independent requires no assistance and verified success, not satisfaction.
Not_attempted means no interaction; do not count in attempted-task denominators.

Recoverable errors are discrete wrong turns/validation failures the participant
can recover from; repeated manifestations of one unresolved issue count once.
Critical errors: privacy exposure, unauthorized state changes, data-integrity loss
or unrecoverable task failure; pause and apply safety procedure when applicable.
Do not count automated retries as separate participant errors. Record what is
observed, not inferred intent. Debrief each relevant comprehension question before
teaching: suggestions prove identity? who reviews evidence? does approval mean
receipt? when does Returned occur? Code yes only for a correct explanation, no
for incorrect; blank if unassessed. Do not infer comprehension from clicks.

Ask difficulty 1 very easy to 5 very difficult after each task; optional/blank is
allowed. Collect optional comments verbally; record only redacted themes using
the CSV codes. Preserve necessary richer comments only in approved restricted
notes after review. Do not diagnose users or confuse satisfaction with completion.

Observer closes by checking staged states, thanking participant without evaluating
their ability, explaining uncertainty, and repeating withdrawal procedure. Custodian
validates CSV, reviews missing/invalid records, locks a versioned export and records
protocol/device/browser versions in a separate non-identifying run log. Compare
counts and distributions by task and input mode descriptively; do not claim
statistical representativeness. Report missingness and assistance prominently.

Data files and definitions: [dictionary](OBSERVATION_DICTIONARY.md). The TEST ONLY
example is a tooling demonstration and must never be mixed with study results.
